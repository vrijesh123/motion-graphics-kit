# Fonts

- **Poppins**, by Indian Type Foundry, from Google Fonts (https://fonts.google.com/specimen/Poppins). SIL Open Font
  License 1.1; the licence text is in `OFL.txt`. Free to embed in videos.
- **Files:** static TTFs Regular 400, Medium 500, SemiBold 600, Bold 700, ExtraBold 800.
- **Why Poppins:** quantiphi.com sets every heading and body style in Poppins, loading weights 400, 500, 600, 700
  and 900 (`sources.md` S8). 900 (Black) is not included here; add `Poppins-Black.ttf` from Google Fonts if a design
  needs it.
- **The logo wordmark is artwork.** Always use the SVG files in `../logo/`; never set the logo in type.
