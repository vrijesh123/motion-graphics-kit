## How they work
**The 5-pillar approach** [S2, S4]:
1. **Foundational AI Platform.** An "Inner Loop" of shared services (planners, memory, LLM routing) inside the
   client's secure tenant.
2. **Enterprise Context & Data.** A semantic layer, "Knowledge Vault and Decision Graph", that turns raw data into
   AI-ready data products, "a proprietary asset that compounds in value".
3. **Lean AI Assembly Line.** An "Outer Loop" of reusable prompts, grounding tools and human-in-the-loop consoles,
   moving "from artisan development to industrial-scale manufacturing".
4. **Human-Centered Design.** Interfaces built into existing workflows to "bridge the execution and adoption gap".
5. **Value Realization.** P&L thesis from day one, business cases, unit economics and change management.

Homepage version of the pillars [S1]: "Sovereign AI Foundation + Enterprise Context & Data + Lean Agent Assembly
Line + Human Centered Design + Value Realization Layer = Compounded Edge".
