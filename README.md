# 3D motion graphics kit (branch `3d-graphics`)

Make short 3D motion graphics videos with Claude Code and [HyperFrames](https://hyperframes.heygen.com)
(Three.js/WebGL + GSAP in HTML, rendered to MP4): brief → script → voice-over timing → 3D scene → MP4.

This branch was split off the 2D kit on `main`. The 3D template, skills and reference library are not set up yet;
see [CLAUDE.md](CLAUDE.md) and [docs/GUIDE.md](docs/GUIDE.md).

Inside:
- `clients/wolfx/` the WOLFx Digital Agency brand pack (from the `wolfx` branch). `clients/_template/` is the blank pack.
- `projects/` one folder per video (empty for now).
- `refrences/` analysed 3D references, text only (empty for now).
- `tools/` Whisper transcripts, caption markup, soundtrack generator, reference prep.
